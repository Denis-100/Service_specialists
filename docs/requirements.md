# Требования и соответствие реализации

## Источник

`Shablon_upravlenia_IT_proektom_dlya_odnoy_komandy.xlsx`, лист «ПРОЕКТ»:

- Название — «Свободно.».
- Идея — сервис записи к специалистам.
- Пользователи — поставщики услуг и клиенты.
- Проблема — затраты времени на обсуждение и поиск свободного места.
- Ценность — быстрый поиск и бронирование свободного времени.
- MVP — услуги и расписание поставщика; выбор даты/времени и отмена клиентом; категории, фильтры, поиск; личный кабинет.
- Критерий успеха — рабочий прототип с проверенным полным циклом.
- Исходно исключены онлайн-оплата, прямой чат с мастером, отзывы и оценки.

Дополнительный запрос заказчика **добавляет отзывы, оценки, модерацию, консультационный чат и вместимость групп**. Он имеет приоритет над первоначальными исключениями. Прямая переписка клиента со специалистом и онлайн-оплата остаются вне объёма.

## Принятые решения

| Требование | Реализация |
|---|---|
| Демонстрационные специалисты | Шесть вымышленных профилей в пяти категориях; стоковые портреты Unsplash |
| Список услуг, опыт, навыки, образование | Каталог, подробное окно профиля, выбор услуги |
| Поиск и фильтры | Имя, профессия, услуги, навыки; категория, цена, формат; сортировка |
| Дата и время бронирования | Только серверные свободные слоты, фиксированный часовой пояс Кирова |
| Несколько участников | Групповые услуги, вместимость 1–50, выбор количества мест, транзакционная проверка остатка |
| Кабинет клиента | Активные, завершённые и отменённые записи; история поиска; отзывы |
| Кабинет мастера | Услуги, интервалы расписания, закрытие слотов, клиенты, отмена и завершение работ |
| Администратор | Модерация отзывов, доступности специалистов и услуг; все записи |
| Онлайн-консультация | Подбор категории по ключевым словам; переход к специалисту |
| Отмена | Только предстоящая активная запись; освобождение вместимости |
| Отзывы | Один отзыв на завершённую запись; публикация после модерации |

## Инварианты

1. Клиент не может отменить чужую запись; мастер управляет только собственным расписанием и клиентами.
2. Бронирование и закрытие слота используют `BEGIN IMMEDIATE`, поэтому проверка и изменение состояния атомарны.
3. Сумма активных участников не превышает вместимость. Отменённые записи не расходуют места.
4. Прошедшие, закрытые и скрытые услуги/слоты нельзя забронировать.
5. Один клиент не может одновременно иметь две активные записи на один слот.
6. Интервалы мастера не пересекаются с учётом длительности услуги; несколько услуг не создают параллельной доступности одного человека.
7. Скрытие специалиста/услуги запрещает новые записи, но не удаляет историю существующих клиентов.
8. Опубликованный рейтинг вычисляется только по одобренным отзывам.

## Ограничения демо

Один город; нет оплаты и уведомлений; консультант без внешнего AI API; нет пользовательского выбора часового пояса. Демо-входы предназначены для проверки сценариев, а не публичного многопользовательского production-сервиса. Начальное расписание не обновляется автоматически, чтобы не перезаписывать изменения мастеров.
