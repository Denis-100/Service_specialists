# Свободно.

Демонстрационный сервис поиска специалистов и бронирования времени. Реализация в ветке `ai_version` основана на листе **ПРОЕКТ** исходного Excel-файла и дополнительных требованиях заказчика.

## Запуск

Требуется Python 3.12+.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python app.py
```

Откройте приложение на порту **5000**. Порт можно изменить переменной `PORT`. SQLite создаётся автоматически при первом запуске в `instance/svobodno.sqlite`. Перезапуск сохраняет данные. Это демонстрационный сервер Flask; для публичной эксплуатации необходим production WSGI-сервер, HTTPS и отдельная настройка безопасности.

## Демо-вход

В окне входа есть кнопки для каждой роли. Общий пароль демонстрационных аккаунтов: `Demo2026!`.

| Роль | Почта | Возможности |
|---|---|---|
| Клиент | `client@svobodno.demo` | Запись, отмена, история встреч и поиска, отзывы |
| Мастер | `master@svobodno.demo` | Услуги сантехника, расписание, записи клиентов |
| Преподаватель | `teacher@svobodno.demo` | Индивидуальные занятия и групповой разговорный клуб |
| Администратор | `admin@svobodno.demo` | Все записи, модерация отзывов, скрытие специалистов и услуг |
| Второй клиент | `ivan@svobodno.demo` | Проверка одновременных записей и вместимости |

Можно зарегистрировать собственного **клиента**. Роль мастера или администратора нельзя получить через регистрацию. Демо-аккаунты общие; не используйте реальные персональные данные. Все имена, квалификации, адреса, отзывы и услуги вымышлены; стоковые фотографии не удостоверяют личность специалиста.

## Что реализовано

- Каталог шести специалистов, категории, поиск по имени/специализации/услугам/навыкам, фильтры стоимости и формата, сортировка.
- Профиль: стаж, навыки, образование, услуги, стоимость, продолжительность, отзывы.
- Выбор услуги, даты и **существующего свободного слота**, адрес выезда и комментарий.
- Индивидуальные записи и группы: количество участников, доступные места, серверная проверка вместимости в транзакции SQLite. Два параллельных запроса не могут переполнить слот.
- Отмена предстоящей записи клиентом, назначенным мастером или администратором. Места возвращаются в доступные.
- Клиент: история записей/вызовов, поиск, собственные отзывы и статусы модерации.
- Мастер: добавление услуг, индивидуальных и групповых слотов, защита от пересечения расписания, закрытие незанятого слота, отмена и завершение встреч.
- Администратор: публикация/отклонение отзывов, скрытие/возврат специалистов и услуг, просмотр/отмена записей.
- Консультационный помощник: подбор по ключевым словам, например «протекает кран» → сантехник. Это **правила, а не LLM**. Чат не является прямой перепиской с мастером.
- Адаптивный интерфейс, сессии, хеширование паролей, CSRF-проверка, серверные ограничения прав.

Все даты и время относятся к **Кирову, UTC+3 (Europe/Kirov)**. Предзаполненное расписание создаётся на 14 дней вперёд относительно первого запуска. В дальнейшем мастер добавляет слоты самостоятельно. Групповое занятие — один слот вместимостью до 50 человек. Интервалы включают длительность услуги; время на дорогу мастер учитывает при размещении слотов.

## Проверка полного цикла

1. Войти клиентом, выбрать сантехника, услугу, день и свободное время; указать демонстрационный адрес и подтвердить.
2. Убедиться, что встреча появилась в кабинете и слот занят. Отменить — слот снова свободен.
3. Выбрать Анну Лебедеву → «Разговорный клуб» и указать несколько участников. Из другого аккаунта проверить остаток мест.
4. Войти мастером: добавить услугу и слот. Пересекающийся интервал отклоняется. Слот с активными записями нельзя закрыть без их отмены.
5. В кабинете клиента есть завершённая демонстрационная встреча с сантехником: оставить отзыв.
6. Войти администратором, опубликовать отзыв. Он появится в профиле специалиста и повлияет на рейтинг.
7. В чате написать «протекает кран» и перейти к рекомендованному специалисту.

## Тесты

```bash
.venv/bin/python -m pytest -q
node --check static/app.js
```

Браузерные тесты (нужен Node.js 20+):

```bash
npm ci
npx playwright install chromium
npm run test:e2e
# Если Chromium уже установлен в системе:
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Playwright запускает отдельный сервер на порту 5051 с временной базой. Проверяет полный цикл трёх ролей, консультацию, мобильные фильтры и загрузку фотографий.

Backend-тесты используют отдельные временные базы и не изменяют данные приложения. Покрыты бронирование, отмена, одновременные запросы к группе, авторизация, CSRF, модерация, регистрация, история поиска, услуги, пересечение слотов и завершение встреч.

## Структура

- `app.py` — Flask API, авторизация, SQLite и демонстрационные данные.
- `static/index.html`, `static/app.js`, `static/style.css` — интерфейс без сборщика.
- `static/photos/` — семь локальных стоковых фотографий Unsplash.
- `scripts/download_assets.py` — воспроизводимая загрузка стоковых фотографий с Unsplash.
- `tests/test_app.py` — интеграционные тесты API и инвариантов бронирования.
- `docs/requirements.md` — требования и принятые решения.
- `docs/photo-sources.md` — источники изображений.
- `instance/` — локальная база и ключ сессии; не попадает в Git.

Нет онлайн-оплаты, SMS/email-рассылок, видеосвязи и интеграций календаря. Ссылку для онлайн-занятия стороны согласуют вне приложения. Для production также нужны управление учётными записями специалистов, восстановление пароля, ограничение попыток входа, аудит действий и резервное копирование. Ключ сессии сохраняется в `instance/session.key`; можно задать `APP_SECRET` через защищённую конфигурацию, не помещая его в Git.
